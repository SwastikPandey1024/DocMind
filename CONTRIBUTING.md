# Contributing

Thank you for contributing to DocuMind AI.

## Development Setup
1. Clone the repository.
2. Create a virtual environment for the backend.
3. Install Python dependencies from backend/requirements.txt.
4. Install frontend dependencies with npm in frontend/.
5. Start the backend and frontend services locally.

## Branch Strategy
- feature/* for new features
- bugfix/* for bug fixes
- hotfix/* for urgent production issues

## Coding Standards
- Follow PEP 8 for Python code
- Use Black and Ruff where possible
- Use ESLint and Prettier for frontend code
- Keep documentation updated with code changes

## Pull Request Checklist
- One feature or fix per pull request
- Include tests when applicable
- Write clear commit messages
- Describe the impact of the change
