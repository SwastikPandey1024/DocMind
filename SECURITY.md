# Security Policy

## Supported Versions
- Main branch and current development releases

## Reporting a Vulnerability
Please report suspected vulnerabilities privately. Do not open a public issue for security concerns.

Send details to the project maintainer via a private channel or email.

## Expected Response
- Acknowledgment within 5 business days
- Status update after triage and remediation planning

## Scope
This includes authentication, file upload handling, API authorization, and environment configuration.
