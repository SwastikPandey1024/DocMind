# DocMind Frontend

This folder contains the production-oriented React frontend for DocMind.

## Structure
- src/app: application shell and bootstrap
- src/components: shared UI primitives and layout components
- src/features: feature-based modules for auth, dashboard, chat, documents, and settings
- src/pages: route-level page components
- src/services: API service layer and network utilities
- src/styles: Tailwind and application styling

## Stack
- React 19
- TypeScript
- Vite
- TailwindCSS
- shadcn/ui-inspired primitives
- React Router
- TanStack Query
- Axios
- React Hook Form
- Zod
